### 見かたは2通り
- **GitHubアプリ**：上のリンク（`.md` ファイル）をタップ。Private のままでも見られます
- **Webサイト（GitHub Pages）**：`.html` ファイル。リポジトリを Public にして Pages をオンにすると
  `https://091165.github.io/family/` で、デザイン付きで見られます

### 構成
```
README.md            ← この目次（アプリのトップ）
hokkaido-2026.md     ← 北海道のしおり（アプリ用）
hawaii-2026.md       ← ハワイのしおり（アプリ用）
index.html           ← Webサイトのトップ
travel.html          ← Webサイトの旅のしおり一覧
hokkaido-2026.html   ← 北海道のしおり（Webサイト用）
hawaii-2026.html     ← ハワイのしおり（Webサイト用）
style.css            ← Webサイト共通のデザイン
hawaii1〜5.jpg       ← ハワイの思い出写真
```

### 旅行が増えたら
- アプリ用：`<行き先>-<年>.md` を作って、上の表に1行追加
- Webサイト用：`<行き先>-<年>.html` を作って、`travel.html` にカードを追加
- 内容を変えたときは `.md` と `.html` の両方を直す
